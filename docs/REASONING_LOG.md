# Reasoning Log

이 파일은 프로젝트 전반에 걸쳐 중요한 설계 결정의 추론 체인을 누적하는 기록이다.
각 이슈 작업 시 Phase 보고서에서 핵심 추론만 옮겨 적는다.

형식:
- **문제** → 문제를 제약 조건으로 재정의
- **추론** → 제약 A → 제약 B → 선택 C 의 논리 흐름
- **패턴** → 이 결정에서 꺼낼 수 있는 재사용 가능한 판단 규칙
